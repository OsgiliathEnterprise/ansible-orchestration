## Why

The Kubernetes API server currently uses auto-signed certificates generated by kubeadm, with no integration to the existing FreeIPA PKI infrastructure. A dormant skeleton of IPA PKI integration exists in `ipa-*.yml` task files but is commented out and uses fragile shell-based commands. This change establishes the FreeIPA PKI infrastructure (sub-CA, ACL, cert profile) needed for Kubernetes certificate management.

## What Changes

- Create `kubernetes-ca` lightweight sub-CA in FreeIPA PKI
- Create CA ACL scoped to Kubernetes hosts and services (replacing overly broad `--hostcat=all`)
- Create `kubeAdministrators` certificate profile with `O=system:masters`
- Add Kerberos ticket validation safeguard before cert operations

## Capabilities

### New Capabilities
- `ipa-pki-infra`: FreeIPA PKI infrastructure setup including sub-CA, CA ACL, and certificate profile for Kubernetes
